# Engineering 1 - Java Game Development

A two-stage software engineering project completed as part of the University
of York Engineering 1 module.

The project involved first developing a Java/LibGDX game against a product
brief, followed by brownfield development in which our team inherited and
extended an existing codebase.

## Project Stages

### Assessment 1 - Initial Development
Developed the initial implementation using Java and LibGDX, applying
object-oriented design and UML modelling to translate a product brief into
a working game.

To view this stage, select the `assessment-1` branch using the GitHub branch
selector.

### Assessment 2 - Brownfield Development
Worked as part of a team to inherit, understand and extend an existing
LibGDX codebase to satisfy the full product brief.

The project also used GitHub Actions for continuous integration, automating
Gradle builds, test execution, Javadoc generation and runnable JAR packaging.

To view the preserved Assessment 2 version, select the `assessment-2` branch.

## Technologies

Java · LibGDX · Object-Oriented Programming · UML · Gradle · GitHub Actions ·
CI/CD · Automated Testing · Javadoc · Git
